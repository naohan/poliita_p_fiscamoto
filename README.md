# Política de Privacidad — FiscaMoto

Este repositorio contiene una página estática (`index.html`) lista para publicar en **GitHub Pages**.

## Publicar en GitHub Pages

1. Sube este repositorio a GitHub.
2. En GitHub, ve a **Settings** → **Pages**.
3. En **Build and deployment**:
   - **Source**: *Deploy from a branch*
   - **Branch**: `main` (o `master`) y carpeta `/ (root)`
4. Guarda los cambios. GitHub te mostrará la URL de publicación.
